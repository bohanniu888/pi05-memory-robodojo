## 仍存在的技术缺口

- `swap_blocks` 的 PhysX CUDA 700 根因尚未定位。
- `press_by_number` 仍为 0，这是相对 DM0.5 最大的得分缺口。
- `cover_blocks` 需要更多集数，才能对能力作任何判断。
- native 50-trial 评测和五维回归尚未完成。
- 1 Hz 视觉历史可能不足以支持自运动计数；action/state 历史尚未测试。

## 发布决策

根工作区不是 Git 仓库，且 `robodojo/` 与 `robodojo/XPolicyLab/` 是嵌套的 Git 仓库/子模块。直接在根目录提交
会遗漏这些仓库的内容。因此发布方案采用：

- 确切的上游提交；
- 已跟踪文件补丁；
- 未跟踪文件覆盖层；
- 精简的项目元数据；
- 不包含数据、权重、checkpoint、日志或镜像。
